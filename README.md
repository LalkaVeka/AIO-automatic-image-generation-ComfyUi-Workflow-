# Начало
Это воркфлоу призван полностью исключить участие человека в процессе генерации изображений. Все процессы между постановкой задачи и получением результата переданы ЛЛМ.
# Функционал
1. Поддержка 3-х моделей генерации: Flux 2 dev, Flux 2 Klein, Qwen Image 25XX.
2. Поддержка 3-х режимов генерации: создание изображения, редактирование изображения, редактирование изображения с применением референсов.
3. Поддержка до 12 референсных изображений<sup>1</sup>
4. Оптимизация исходной задачи.
5. Автоматическое написание промпта и его коррекция.
6. Поддержка двойного и тройного семплирования изображений.
7. Апскейл результата генерации.

<sup>1</sup> до 3-х референсов для генератора и до 12 референсов для написания промпта
# Требования к моделям
## Минимальные
1. Комплект моделей Flux 2 Klein.
2. [Tiny LLM](https://huggingface.co/mradermacher/Tiny-LLM-GGUF).
3. Любая LLM с функцией зрения.

## Полные
1. Комплект моделей Flux 2 dev, Flux 2 Klein, Qwen Image 25XX.
2. [Tiny LLM](https://huggingface.co/mradermacher/Tiny-LLM-GGUF).
3. Три любые LLM с функцией зрения.
4. Комплект моделей SeedVR2.

Воркфлоу тестировался на LLM Gemma 4 26B A4B QAT, которая выполняла функции 3-х применяемых в воркфлоу LLM.
# Установка
1. Установите ComfyUI.
2. Установите LM Studio.
3. Скачайте и установите необходимые модели в Comfy и LM Studio.<sup>2, 3</sup>
4. Установите следующие расширения в Comfy<sup>4</sup>:
   - [ComfyUI-KJNodes](https://github.com/kijai/ComfyUI-KJNodes)
   - [rgthree-comfy](https://github.com/rgthree/rgthree-comfy)
   - [ComfyUI-Easy-Use](https://github.com/yolain/ComfyUI-Easy-Use)
   - [ComfyUI-Impact-Pack](https://github.com/ltdrdata/ComfyUI-Impact-Pack)
   - [was-node-suite-comfyui](https://github.com/ltdrdata/was-node-suite-comfyui)
   - [ComfyUI-Unload-Model](https://github.com/SeanScripts/ComfyUI-Unload-Model)
   - [comfyui_LLM_party](https://github.com/heshengtao/comfyui_LLM_party)
5. Настройте LM Studio:
   - Откройте раздел Developer.
   - В настройках сервера (Server Settings) выставите:
      - Server Port --> 16001
      - Require Authentication --> Выкл
      - Загрузка модели по требованию --> Вкл
      - Сохранять только последнюю загруженную модель --> Вкл
   - Запустите сервер.

<sup>2</sup> Воркфлоу может работать без части моделей за счет ограничения функционала.
<sup>3</sup> Вероятнее всего, Comfy предложит сам скачать модели генерации при запуске воркфлоу.
<sup>4</sup> Также возможны автоматические скачивание и установка через Comfy. Управление расширениями --> Отсутствующие узлы.
# Запуск
0. После полной установки для повторного использования воркфлоу достаточно запустить LM Studio с запущенным сервером.
1. Перетащите .json файл (вкладка релизы) на рабочую область Comfy.
   Вы увидите это:
   ![Общий вид](https://imgur.com/ngbvBK0.png)
2. Перейдите к блоку настроек воркфлоу.
   ![Блок настроек](https://imgur.com/1vbT09Z.png)
3. В блоке Step 0 выберите ранее скачанные модели. Для получения точных имен LLM перейдите по локальной ссылке http://127.0.0.1:16001/v1/models
4. Далее настройте воркфлоу под необходимую задачу в блоках Step 1 - Step 13. Каждый блок содержит собственную инструкцию.
5. Перейдите к блоку изображений.
   ![Блок изображений](https://imgur.com/dHVq5FK.png)
6. При необходимости добавьте изображения-референсы.
7. Запустите воркфлоу.
8. Профит.
